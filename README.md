# The Boomer's AI Passage

From Curious to Confident. No hype. No jargon. Just what it can do for you.

Live at https://boomersaipassage.com (GitHub Pages).

- `.tools/app.html` is the single-page app and the source of all content (tool picks, problems, word list, agents).
- `.tools/build.js` builds the full site from it: `node .tools/build.js .tools/app.html .`
  (run from a temp folder and copy back, since the build clears its output folder).
